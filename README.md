# TP1 |  Curriculum en html5 y css

## Proyecto

El objetivo principal de este proyecto consiste en crear desde cero un currículum vitae interactivo utilizando etiquetas semánticas de html5 y estilos con css.
Para llevarlo a cabo trabaje con el editor de códigos Visual Code y una pantalla de 1536x695.2px.
Primero se maqueto toda la estructura html5 y luego se le incorporo diseño y organizacion de elementos con flexbox.
