# tp 3| portfolio

## Proyecto

El objetivo principal de este proyecto en modificar el curriculum vitae que realizamos en el tp 1 y convertirlo en un portfolio tilizando etiquetas semánticas de html5 y estilos con css.

Para llevarlo a cabo trabaje con el editor de códigos Visual Code y una pantalla de 1536x695.2px.
primero se diseñó la pieza grafica en figma y luego se maquetó toda la estructura html5 y luego se le incorporó diseño con css, organizandolo con flexbox y grid.
